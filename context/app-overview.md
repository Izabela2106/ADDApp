## Overview

dhdTimer is an application for running random timers. User can choose a range and unit(seconds, minutes) and then app is running timers within these range. After every timer end there is an audio signal. 

## Goals

1. User can select range and unit in folder.
2. user clicks start and random timers are running one by one
